时光匣是一款访问洛克王国经典网页版的第三方浏览器，本版为实验性测试包。

- 修正 Flash 图片取消加载后，旧图片仍可能交给新任务的引擎问题。针对战斗药品图标串图排查；实际游戏内图标和 PP 恢复仍需验证。
- README 补充腾讯及相关权利人版权归属、第三方浏览器定位、个人学习研究用途与免责声明。
- 保留现有登录、服务器连接、活动资源适配和游戏全屏入口。

引擎图片回归、APK 构建、lint、单元测试和八项本地 Gecko 浏览器样例均通过后才发布。它们不等于完整游戏兼容：部分活动仍可能报错，官网背景声音、战斗文字、PP 恢复和长时间稳定性尚未全部验收。

安装 `time-casket-0.1.27-debug.apk`，不需要测试程序。Android 8.0 起可用；下载后可用 `SHA256SUMS.txt` 核对文件。只有相同签名的安装包才能保留数据覆盖升级。此云端测试包的签名可能与手机已有的本地调试包不同；如提示签名冲突，请勿卸载或清数据，先反馈处理。
